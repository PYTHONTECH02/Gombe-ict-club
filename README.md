# Gombe ICT Club Platform

## Stack
- React
- Vite
- Supabase
- Tailwind-ready structure

## Features Planned
- Google Authentication
- Email + Password Authentication
- Admin Dashboard
- Dynamic Lessons
- Realtime Leaderboards
- Cyber & Coding Progress Tracking
- Avatar Uploads
- Gaming & Announcements Management

## Install

npm install

## Run

npm run dev

## Build

npm run build

Upload the `dist` folder to InfinityFree hosting.
